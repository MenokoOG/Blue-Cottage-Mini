# 2. Answer only from cited open sources, and carry the source on every chunk

Recorded: 2026-10-29. Decided: 2026-10-16 (release 0.2.0, commit `e9124b0`).

## Status

Accepted. Built for facts, namesakes and history. Move-by-move text is deliberately absent.

## Context

The first version was built from the TITF handbooks. For 0.2.0 the project lead chose to replace them with free public material and to cite every source. Open material covers the facts about the patterns (names, periods, history, meanings). It doesn't cover the movements: published sequences are copyrighted and no free-licensed source exists. Public listings also disagree on some counts (itftaekwondo.com lists Tong-Il as 42 movements and Choi-Yong as 45; the app uses 56 and 46, per `CHANGELOG.md`).

A wrong technique in a training app is worse than a gap.

## Decision

1. Every corpus chunk has a `source` of `{label, url}` ([`corpus.ts`](../../src/lib/corpus.ts)). The coach returns the deduped sources with each answer and the UI shows them.
2. Pattern data is generated by `tools/build_open_data.mjs` from Wikipedia (CC BY-SA 4.0, with revision ids) and cross-checked against itftaekwondo.com for facts only. Videos are embedded from YouTube, never copied, and load on click.
3. Known disagreements between sources are published on `/sources`, not hidden.
4. No move-by-move text ships. `src/data/movements.json` is the drop-in slot for text the instructor writes or approves. The stepper, the movement quiz questions and the movement chunks switch on when it's filled.
5. Each persona says: answer only from the excerpts, never invent movements, and point to the video and a qualified instructor when asked for a sequence.
6. We rejected drafting sequences from model memory.

## Consequences

- The corpus is 57 chunks today. It answers questions about meaning, namesake, period, belt, rank and counts. It can't answer how to perform a pattern.
- Provenance is by chunk, not by claim. The source list says which excerpts were in the prompt. It doesn't prove that each sentence of the answer came from them. Nothing checks that.
- Counts and belts are cross-checked but not freely licensed, which the README says.
- Wikipedia is the single source for most facts. A bad edit upstream is only caught when the data is regenerated and someone reads the diff.
